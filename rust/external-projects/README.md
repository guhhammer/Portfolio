# External Rust projects

These Rust projects are too large to live inside the portfolio, so each has its own repository. The index of all of them is the [rust-projects](https://github.com/guhhammer/rust-projects) repository; every file here is a short pointer with a description and the link.

What these projects show, taken together: production-ready Rust applications, backend APIs, desktop applications (Tauri), distributed systems, WebAssembly, authentication and security, PostgreSQL and MongoDB, Docker deployments, and full-stack Rust projects.
