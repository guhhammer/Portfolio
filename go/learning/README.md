# Learning modules

Nine tiny Go modules, one per language feature, written while learning the language. Run any of them with `go run .` inside its folder.

| Module | Topic |
| --- | --- |
| `hello/` | First program and the `go mod init` / `go run` / `go build` workflow (`terminal-cmds.txt`). |
| `simple/` | Functions with multiple return values and error handling (`intDivision`). |
| `arrays/` | Arrays versus slices, capacity, and timing loops over large slices. |
| `pointers/` | Pointers and value versus reference semantics. |
| `strings/` | Strings, runes and the `strings` package. |
| `structs/` | Structs, methods and interfaces (`gasEngine`, `electricEngine`, an `engine` interface, an `owner`). |
| `generics/` | Type parameters: a generic `car[T]`, `sumSlice`, `isEmpty`. |
| `goroutines/` | Serial versus concurrent execution of simulated database calls. |
| `channels/` | Channels, buffered channels and `select` with concurrent price checkers. |
