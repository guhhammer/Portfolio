# Certificates

Proof of completed training and attended talks.

- [`courses/`](courses/) — 38 online-course certificates grouped by issuer: the IBM DevOps & Software Engineering track (17), a Duke University Rust specialization (6), a blockchain / Solidity curriculum (11), and single courses from Yale, Penn and Sydney.
- [`talks/`](talks/) — 33 attendance certificates from university tech talks and workshops (2019-2020), on security, reverse engineering, machine learning, IoT, web and career topics.

The course certificates are in English; the talk certificates are in Portuguese. The blockchain certificates back the work in [`../blockchain/`](../blockchain/), and the Rust ones the work in [`../rust/`](../rust/).
