# Academic writing

Reports, papers, models and presentations from the Computer Science degree at PUCPR (Curitiba, Brazil, 2018 to 2022) and an exchange semester at CSUSM (California, 2020). Everything that was written for a course is in the language of that course: the PUCPR documents are in Portuguese, the CSUSM ones in English. Every folder has an English README that says what each document is, and file and folder names are in English. Third-party material (lecture slides, textbook chapters, papers used as references) was removed; what remains is my own or my team's work.

| Folder | What it is |
| --- | --- |
| [`final-paper-diskify/`](final-paper-diskify/) | The capstone thesis: proposal and final project for Diskify, a music NFT marketplace, with presentations, interview data, an HTML mockup and the sprint plan. The code lives in [`blockchain/solidity/diskify-music-nft-marketplace/`](../blockchain/solidity/diskify-music-nft-marketplace/). |
| [`latex-projects/`](latex-projects/) | LaTeX sources of eight papers written during the degree (GAN data augmentation, the Diskify feasibility study, business plan and AHP evaluation, a survey, two Monte Carlo simulations, a product idea). |
| [`project-viability-analysis/`](project-viability-analysis/) | A 54-page feasibility study of Diskify (market, technical, financial) and an AHP multi-criteria evaluation of an IT project portfolio, with the financial models. |
| [`software-architecture/`](software-architecture/) | Architecture models (Astah), an architectural analysis of the LiberumOratio system, a space-based-architecture presentation and the final architecture document. |
| [`software-modelling-uml/`](software-modelling-uml/) | UML modelling: a sales-commission system (use cases, conceptual model, sequence diagrams), a distribution-and-factory project with design patterns. |
| [`research-methods/`](research-methods/) | A systematic literature review, a survey on the state of the art of AI, a grounded-theory study and the course activities. |
| [`business-and-entrepreneurship/`](business-and-entrepreneurship/) | A startup idea ("Ingredient", later "Ruptify") taken from ideation to pitch: canvases, personas, prototypes, user interviews, business model canvas. |
| [`exchange-semester/`](exchange-semester/) | The CSUSM software-engineering course (assignments, exercises, final exam) and the GoNavy team project, in English, plus the semester transcript. |
| [`mathematical-logic/`](mathematical-logic/) | A Prolog exam (family relations, restaurant preferences) rewritten in English and a critical review of the graphic novel *Logicomix*. |
