# Software architecture

Course on choosing the high-level structure of a system and justifying it against the qualities the business needs (PUCPR, 2021). Models are Astah files (`.asta`, open with [Astah](https://astah.net/)); documents are in Portuguese.

| Folder | What it is |
| --- | --- |
| `final-architecture-document/` | The final architecture document (25 pages: requirements, quality attributes, component, class and sequence views, deployment) with its Astah model, the analysis write-ups and the figures. |
| `liberum-oratio/` | The system carried through the semester, LiberumOratio: the initial model and two earlier versions, the component model, the enhanced architecture and the written architectural analysis. |
| `space-based-architecture/` | Team presentation on the space-based architecture style, with the component model, diagrams and the speaker notes. |
| `classes/class-01` to `class-12` | Weekly work: reflections, a first presentation, requirements and use cases for a weather app, class exercises in Astah, the CultBook, iJobs, Adventure Time and Ye Old RH case studies (component models, an ATAM evaluation). |
