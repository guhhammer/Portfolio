# Project viability analysis

Course on assessing whether a software project is worth building (PUCPR, 2022): market, technical and financial feasibility, competitive positioning and multi-criteria project selection. Both studies use Diskify, the music NFT marketplace that became the capstone, as the case. Written in Portuguese; LaTeX sources are in [`latex-projects/`](../latex-projects/).

## Diskify feasibility study (`diskify-feasibility-study/`)

One continuous study, delivered in three graded parts and revised over thirteen checkpoints with the professor's feedback:

- `feasibility-study-final.pdf`: the complete 54-page study (market, technical and financial feasibility).
- `part-1-market-feasibility.pdf` and `part-1-market-feasibility-annotated.pdf`: the market part as submitted and with the professor's annotations (Blue Ocean strategy, Porter's five forces, personas, value matrix, business model canvas).
- `part-2-technical-feasibility.pdf`: the technical part (architecture, components, production and operations, human resources).
- `business-definition.pdf`, `diskify-article.pdf`: the business definition and the article written in the SBC (Brazilian Computer Society) template.
- `financial-model/`: the investment-analysis and financial-analysis spreadsheets behind part 3; `value-matrix.xlsx` supports part 1.
- `figures/`: the diagrams and canvases used in each part.

## AHP project portfolio (`ahp-project-portfolio/`)

`ahp-project-evaluation.pdf` applies the Analytic Hierarchy Process to rank IT projects on market, technical and financial criteria, with `multicriteria-model.xlsx` holding the pairwise comparisons and `figures/` the hierarchy tree, criteria weights and consolidated results.
