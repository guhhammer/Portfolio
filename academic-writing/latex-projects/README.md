# LaTeX projects

LaTeX sources of eight papers written during the degree, all in the ASME journal template (`asme2ej.cls`, one column). Each folder is self-contained: the `.tex` file, the bibliography, the class and style files, the figures and a `Makefile` (`latex` + `bibtex` + `dvips` + `ps2pdf`; `latexmk -pdf asme2ej.tex` also works). The papers are in Portuguese; where the compiled PDF is part of another folder it is linked below.

| Folder | Paper |
| --- | --- |
| `gan-red-blood-cell-augmentation/` | Report on using GANs to augment a red-blood-cell image dataset (compiled PDF and code in [`python/computer-vision/`](../../python/computer-vision/)). |
| `diskify-feasibility-study/` | Feasibility analysis of the Diskify project, 900 lines of LaTeX; the PDF is [`project-viability-analysis/diskify-feasibility-study/feasibility-study-final.pdf`](../project-viability-analysis/diskify-feasibility-study/feasibility-study-final.pdf). |
| `diskify-ahp-project-evaluation/` | Multi-criteria decision process (AHP) for evaluating IT projects, applied to Diskify; PDF in [`project-viability-analysis/ahp-project-portfolio/`](../project-viability-analysis/ahp-project-portfolio/). |
| `diskify-business-plan/` | Business plan for Diskify. |
| `ai-state-of-the-art-survey/` | Survey on knowledge of the state of the art in artificial intelligence; PDF in [`research-methods/survey/`](../research-methods/survey/). |
| `monte-carlo-contagion-estimate/` | Monte Carlo test for predicting new infection cases when in-person classes resume. |
| `investment-simulation-by-asset-class/` | Investment simulation by asset class. |
| `ruptify-fruit-idea/` | Early write-up of the Ruptify product idea from the entrepreneurship course. |
