# Exchange semester (CSUSM, 2020)

One semester at California State University San Marcos, taught in English. This folder keeps the Software Engineering course (CS 441) and the semester's team project; the operating-systems C++ work from the same semester is in [`cpp/operating-systems/`](../../cpp/operating-systems/). `semester-grades.png` is the transcript.

## GoNavy team project (`gonavy-team-project/`)

A web application for managing an NROTC (Naval Reserve Officers' Training Corps) unit, built by a team of three in PHP and MySQL: the final presentation and the mid-term one, the database dump, the Astah system model, component and system diagrams, and screenshots of the PHP pages. The application's source is in [`typescript-javascript/nrotc-management-app/`](../../typescript-javascript/).
