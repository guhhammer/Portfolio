# Software modelling (UML)

Course on planning object-oriented software with UML and design patterns (PUCPR, 2019). Models are Astah files (`.asta`) and one StarUML file (`.mdj`); reports are in Portuguese.

| Folder | What it is |
| --- | --- |
| `assignment-1-sales-commission/` | A sales and commission system modelled with the full diagram set: use cases (register purchased and sold products, authorize transaction, commission), the conceptual model and matching sequence diagrams, exported as PNG with the report and the Astah model. |
| `distribution-and-factory-project/` | The semester project, a distribution-and-factory problem: the project and structural models, the diagram figures and the presentation deck. |
| `activities-3-and-4/` | In-class activities 3 and 4 (models and write-up). |
| `exercises/` | Class exercises, a first version of assignment 4, and short notes on association vs composition, include vs extend and the order in which diagrams are produced. |
