# Web programming course (2019)

The university course where I learned the browser side of the web: HTML, CSS, JavaScript, jQuery, then PHP and XML on the server. The folders follow the order of the classes; the final project is a complete webmail client.

| Folder | What it contains |
| --- | --- |
| `class-01-html-forms-and-media/` | A multi-page site for the Rock in Rio festival: home, registration form, "about", video page with embedded YouTube players, and a shop page; plus the class-day test pages (`tests/`, `misc/`). |
| `class-02-html-page/` | A second static page. |
| `class-03-css/` | Styling exercises: a registration form and tables with external stylesheets. |
| `class-04-javascript-and-jquery/` | First JavaScript: an array of people rendered into an HTML table with jQuery. |
| `class-05-calculator-v1/`, `class-06-calculator-v2/` | A four-operation calculator, first with one handler per operation, then refactored. |
| `class-07-dom-and-events/` | Form validation with class toggling, and a song list that adds and removes items from an array. |
| `class-08-php-intro/` | First PHP scripts: variables and conditionals, functions, arrays and `foreach`. |
| `class-09-php-and-xml/` | Reading and writing XML from PHP (`SimpleXML`, `DOMDocument`). |
| `exercise-06-html-page/` | Graded exercise: a song list with position highlighting. |
| `exam/` | The practical exam: a navigation page, a validated registration form and an image page. |
| [`final-project-bubble-webmail/`](final-project-bubble-webmail/) | **Bubble**, the final project: a webmail client with accounts, inbox, sent items, drafts, favorites, junk mail, deleted items and archive, search, and a message viewer, backed by PHP and XML files. |

Open any `index.html` in a browser for the front-end classes; the PHP classes and the final project need a PHP-enabled web server (for example XAMPP or `php -S localhost:8000` inside the folder).
