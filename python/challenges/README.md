# Coding challenges and side experiments (Python)

Small stand-alone pieces outside any course.

| Folder | What it is | Run |
| --- | --- | --- |
| `armstrong-number/` | One-line check of Armstrong (narcissistic) numbers: a number equals the sum of its digits raised to a power. The same problem is solved in Haskell, C++ and Java in [`../../haskell/challenges/`](../../haskell/challenges/), [`../../cpp/challenges/`](../../cpp/challenges/) and [`../../java/challenges/`](../../java/challenges/) | `python3 armstrong_number.py` |
| `label-it-kivy-prototype/` | Prototype of a mobile app ("Label it") for labelling meme images, built with Kivy: a main screen with a 3x3 grid of picture buttons, gallery, camera and settings screens, and a bottom bar to switch between them. The plan was to label images automatically with machine learning; only the UI skeleton was built | `pip install kivy && python3 label_it.py` |
