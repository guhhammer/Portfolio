# 3D graphics software construction (Python)

Coursework from the "3D Graphics Software Construction" course at PUCPR (2018): the vector and matrix mathematics behind computer graphics, worked entirely in Jupyter with NumPy and matplotlib, from vectors and dot/cross products to lines, planes, drawing figures along curves, matrices and basic image processing.

For a non-technical reader: these notebooks build up, from scratch, the maths a graphics program uses to place and move shapes in 2D and 3D space, plotting every step.

| File | What it is |
| --- | --- |
| `classes/class-01-04-jupyter-recursion-and-vectors.ipynb` | Jupyter and Markdown basics, Euler's number by recursion, and vectors as tuples: addition, scalar multiplication, magnitude, unit vector, dot product and the angle between vectors |
| `classes/class-05-parametric-lines.ipynb` | The parametric equation of a line P(u) = P0 + u·t, plotted |
| `classes/class-06-circles-along-curves.ipynb` | Drawing circles along a curve and along a parametric line |
| `classes/class-07-composite-figure-along-a-curve.ipynb` | A composite figure (a boat) anchored at a point and repeated along a sine curve |
| `classes/class-08-planes-and-3d-plots.ipynb` | Plane equations and 3D surface/contour plots |
| `classes/class-09-figure-along-a-cubic-and-a-line.ipynb` | A square, triangle and pentagon drawn as one figure along a cubic curve and a line |
| `classes/class-10-vector-exercises.ipynb` | Sixteen exercises: sums, magnitudes, direction cosines, dot and cross products, angles, perpendicularity and line equations |
| `classes/class-11-plane-through-three-points.ipynb` | Vector, matrix and parametric equations of the plane through three points, with quiver plots |
| `classes/class-12-map-filter-reduce-and-numpy-matrices.ipynb` | map / filter / reduce, lambda calculus and building NumPy matrices |
| `classes/class-14-image-processing.ipynb` | Image processing with NumPy: RGB matrices, cropping, greyscale, colour maps, median filter and rotation |
| `vector-spaces-assignment.ipynb` | Team essay on the history, definition, properties, examples and applications of vector spaces |
| `opengl-software-report.docx` | Short report on OpenGL |

The notebooks keep their outputs; the image-processing notebook needs its giraffe images, which are not included. Duplicate merged notebooks, the professor's slides and unused images were removed. The markdown is translated; the mathematics is unchanged.
