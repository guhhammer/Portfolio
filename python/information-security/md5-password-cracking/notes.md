# Notes (translated from the original read-me)

IT = item, P = part; for example `IT01_P1` = item 1, part 1. Files were opened in the order of their numbers.

Deliverables mapping: item 1 = `IT01_P1`, `IT01_P2` and `Funções_IT01`; item 2 = `IT02_P1` and `Funções_IT02`; item 3 = `IT03_P1`, `IT03_P2`, `Funções_IT03_P1`, `Funções_IT03_P2`; report = `report.docx` plus the spreadsheet `cracking-times.xlsx` and the raw results in `cracking-times.txt` and `test-users.csv`.

The original PyCharm project folder (`HASHPROJEKT`) only contained the virtual environment; the item scripts were kept inside the report.
