# SQL

Relational modelling and SQL coursework, translated to English. Every script in this folder was executed end to end against MariaDB 11 (MySQL-compatible) and the query results were checked against the originals.

| Folder | What it is |
| --- | --- |
| [`databases/`](databases/) | Databases course (PUCPR, 2019): a tech-events database with 35 verified queries (joins, aggregates, CTEs, CASE), six smaller schemas (online store, video rental, company, university enrolment, shopping mall, an economic-freedom index in wide and entity-attribute-value layouts), an exam on fixing and querying a car-registry model, plus the ER diagrams, data dictionary and write-ups produced along the way. |
