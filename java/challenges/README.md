# Java coding challenge

`ArmstrongNumber.java` checks whether a number is an Armstrong (narcissistic) number, with a tail-recursive integer power and a character-to-digit lookup. Build and run:

```sh
javac ArmstrongNumber.java && java ArmstrongNumber
```

The same problem is solved in Python, Haskell and C++ under `python/challenges`, `haskell/challenges` and `cpp/challenges`.
