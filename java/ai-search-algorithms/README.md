# AI search algorithms (Java)

Coursework from the Artificial Intelligence course at PUCPR (2021), implemented in Java: graph search over the map of Brazil.

- [`state-space-search/`](state-space-search/) — breadth-first, depth-first (plain, depth-limited, iterative-deepening), greedy best-first and A* search over the 27 Brazilian states, with a timing comparison.

The game-playing and expert-system parts of the same course are in Python, in [`../../python/artificial-intelligence/`](../../python/artificial-intelligence/).
