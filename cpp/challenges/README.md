# C++ coding challenge

`armstrong_number.cpp` checks whether a number is an Armstrong (narcissistic) number: it converts the number to characters, raises each digit to the given power with a tail-recursive helper and compares the sum with the number. Build and run:

```sh
g++ -std=c++17 -o armstrong_number armstrong_number.cpp && ./armstrong_number
```

The same problem is solved in Python, Haskell and Java under `python/challenges`, `haskell/challenges` and `java/challenges`.
